# Reborde (P7 Borders)

Código de [P7 Borders](https://github.com/prasannavl/p7-borders-shell-extension) (versión 58 de
extensions.gnome.org), con licencia MIT (ver LICENSE), copiado sin cambios para el módulo
Reborde de PowerMichi (`modulos/reborde.js`). Usa el mismo esquema de ajustes que la extensión
original (`org.gnome.shell.extensions.p7-borders`), así que conserva su configuración.

- `common/`, `shell/`: el gestor de bordes que corre dentro de GNOME Shell.
